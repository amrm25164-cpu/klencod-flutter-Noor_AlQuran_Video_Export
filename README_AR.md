# نور القرآن — مشروع Flutter أولي

واجهة عربية RTL بتصميم أخضر زمردي وذهبي، مهيأة للتطوير في Klencod IDE أو أي بيئة Flutter.

## الموجود حاليًا
- شاشة إعدادات أولية لاستوديو فيديو القرآن: اختيار السورة والقارئ والخلفية والمقاس، مع خيارات الترجمة والآيات والتكرار. زر المعاينة يعرض الإعدادات فقط ولا يصدر MP4 بعد.
- شاشة رئيسية وتنقل سفلي.
- فهرس أسماء السور الـ114.
- عرض نص سورة الفاتحة (يجب تدقيقه قبل النشر).
- بحث أولي بأسماء السور.
- تبديل الوضع الليلي.
- واجهة الاستماع واختيار القارئ والتكرار (بدون ملفات صوت فعلية).
- علامات قراءة تجريبية أثناء جلسة التشغيل.
- شاشة مميزات تشمل التفسير والترجمة والصلاة والقبلة والأذكار والاختبارات والتنزيل.
- عداد تسبيح يعمل.

## ما لم يكتمل بعد
هذه ليست نسخة إنتاجية ولا تحتوي قاعدة القرآن كاملة؛ بقية السور تعرض تنبيهًا بدل نص الآيات. كما أن التلاوات، التفسير، الترجمات، مواقيت الصلاة والأذان، القبلة، الإشعارات، التخزين الدائم، ويدجت النظام، وتنزيل الصوت ليست مفعلة فعليًا بعد. لا تستخدم التطبيق كمرجع قرآني قبل ربط مصدر موثوق ومراجعة النص.

## فتحه في Klencod IDE
1. أنشئ مشروع Flutter جديدًا باسم `noor_al_quran` من داخل Klencod IDE.
2. استبدل ملف `lib/main.dart` بالملف الموجود هنا، واستبدل `pubspec.yaml`.
3. انسخ مجلد `assets` أيضًا.
4. شغّل `flutter pub get` ثم شغّل التطبيق.

إذا كان Klencod يدعم فتح مجلد مشروع كامل، فك ضغط هذا الأرشيف وافتح المجلد، ثم استخدم خيار بناء APK في IDE.

## بناء APK
على بيئة Flutter مجهزة:
`flutter pub get`
`flutter build apk`

المشروع يحتاج Flutter SDK وAndroid SDK متوافقين. ملف APK لم يُبنَ ضمن هذه الحزمة، ولم يتم اختبار تشغيل Flutter في بيئة بناء هنا.


## استوديو فيديو القرآن — تصدير MP4 أولي
- تمت إضافة اختيار ملف صوتي واختيار صورة خلفية من الهاتف.
- زر التصدير يستدعي FFmpeg لإنشاء MP4 مدته تتبع مدة ملف التلاوة، مع تأثير تكبير/تحريك بطيء للصورة.
- الناتج يحفظ في مجلد بيانات التطبيق باستخدام `path_provider`.
- يلزم تنزيل الحزم عبر `flutter pub get`، واختبار التوافق في نسخة Klencod/Flutter المستخدمة.
- النسخة الحالية لا تولّد مشاهد فيديو AI ولا تضيف نص الآيات/الترجمة داخل الفيديو؛ خياراتها ظاهرة فقط إلى أن تُربط بيانات الآيات والتوقيتات. لا توجد تلاوات أو خلفيات مرخّصة مرفقة.
- الاعتماديات الجديدة: `file_picker`, `path_provider`, `ffmpeg_kit_flutter_new`.
